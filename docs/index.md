# Tableau Mastery Path

A structured, module-wise Tableau training program that takes you from
connecting your first data source to designing a full enterprise BI program
— with step-by-step workflow instructions, worked calculated-field formulas,
and a hands-on exercise in every module.

This track is **not** about coding — it's about learning Tableau itself as a
real business-intelligence tool: connecting to data, building visualizations
and dashboards, writing calculated fields and LOD expressions, securing and
governing content, and running BI at enterprise scale.

## How the program is organized

| Level | Focus | Modules |
|-------|-------|---------|
| [Level 1 · Entry](level-1/index.md) | Connecting to data, first visualizations, chart types, dashboards, calculated fields, filters/parameters, maps | 9 topics + 1 project |
| [Level 2 · Intermediate](level-2/index.md) | Advanced calculated fields, dashboard interactivity, blending/joins/relationships, Tableau Prep, publishing | 9 topics + 1 project |
| [Level 3 · Advanced](level-3/index.md) | Advanced LOD expressions, server/cloud administration, row-level security, governance, embedding | 9 topics + 1 project |
| [Level 4 · Master](level-4/index.md) | Enterprise architecture, BI Center of Excellence, advanced analytics integration, licensing, capstone | 9 topics + 1 capstone |

## How to use this site

- Work through each level in order — later modules assume earlier ones.
- Every topic page has numbered, step-by-step workflow instructions with
  exact Tableau UI elements (Data pane, Shelves, Marks card, Show Me panel)
  named — follow along inside the actual Tableau application.
- Calculated-field and LOD-expression formulas are worked against a small
  fictional retail dataset defined right in the lesson, so you can check
  every result by hand before trusting it against your own data.
- Each topic ends with a cheat-sheet table of the key concepts covered, plus
  an **Exercise** to practice the workflow on your own workbook.
- Each level ends with a project that combines everything learned in that
  level.
- Use the search bar (top of the page) to jump straight to a topic.

Start here → [Level 1 · Entry](level-1/index.md)

## What you'll need

[Tableau Desktop](https://www.tableau.com/products/desktop) (a free trial or
[Tableau Public](https://public.tableau.com/) works for Level 1) to build
along with the lessons. Tableau is a GUI desktop application, so this track
is verified for UI and formula accuracy rather than live execution — every
step names the exact menu, pane, or shelf involved, and every calculated
field is worked by hand against the lesson's dataset so you can check the
result yourself.

🎥 **Prefer video?** Watch the [Mastery Path video series](https://youtube.com/@sigilipelli) on YouTube — Shorts and full walkthroughs of these lessons.
