# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: understand what Tableau is and how its products fit together, connect
to your first data sources, build and format core chart types, combine them
into an interactive dashboard, write your first calculated fields, and use
filters, parameters, table calculations, and maps — then ship a small
end-to-end sales performance dashboard that ties it all together.

By the end of this level you'll be comfortable navigating Tableau Desktop,
connecting to and shaping real data, choosing the right chart for a
question, building calculated fields and using filters/parameters/table
calcs, and will have produced a real deliverable: a multi-sheet, interactive
sales performance dashboard.
