# Tableau Mastery Path

A free, structured, module-wise Tableau training program — entry level to
master level, with step-by-step workflow instructions, worked calculated-field
formulas, and a hands-on exercise in every module. Focused on real BI
analyst skills: connecting data, building visualizations and dashboards,
calculated fields and LOD expressions, row-level security, and enterprise
governance.

**Live site:** https://sigilipelli.github.io/tableau-mastery-path/

## Contents

- **Level 1 · Entry** — connecting to data, first visualizations, chart types, dashboards, calculated fields, filters/parameters, table calculations, maps, sales dashboard project
- **Level 2 · Intermediate** — advanced calculated fields, dashboard interactivity, blending/joins/relationships, Tableau Prep, publishing
- **Level 3 · Advanced** — advanced LOD expressions, server/cloud administration, row-level security, governance, embedding
- **Level 4 · Master** — enterprise architecture, BI Center of Excellence, advanced analytics integration, licensing, capstone

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
